# AI use disclosure

Generative AI was used as a programming, debugging, organization, and drafting assistant during the development of this capstone project.

The repository makes the analytical choices explicit: data inclusion rules, target construction, feature definitions, chronological splits, hyperparameter grids, frozen model configurations, test protocol, and robustness checks. Generated code and text were reviewed against the project data and course requirements, and the reproducibility pipeline is designed so that the submitted outputs can be independently rerun.

The project does not use generative AI to create observations, labels, commodity prices, or conflict events.
